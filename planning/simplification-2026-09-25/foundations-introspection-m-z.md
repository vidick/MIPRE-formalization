## Rejected with evidence

- `StateStability.testAcceptance_state_stability` (StateStability.lean:77) vs `ValueStability.testAcceptance_stability_left` (ValueStability.lean:132): the first varies the *state* for fixed PVMs, the second varies one *PVM* for a fixed state; different theorems, both used.
- `Measurements.joint_measurement_isPVM` (Measurements.lean:33, commuting product `P a * Q b` on one space) vs `ValueStability.joint_isPVM` (ValueStability.lean:101, Kronecker `M a ⊗ₖ Q b`): different statements, each with its own consumers (ConditionalNormalizer / HonestMagicSquare vs StateStability).
- `TypedEstimates.sampling_prefix_estimate` (TypedEstimates.lean:105) vs `MIPRE.Introspection.sampling_prefix_estimate` (SamplingTests.lean:82): same final name, different statements (parsed typed game vs generic game with pushforward law); both tagged. Naming only.
- `TypedExtraction.exists_strategy_of_terminal_form` (:176) is not the δ=0 case of `exists_strategy_of_approx_terminal_form` (:220): the exact form assumes equality on `.pair` constructors only and no PVM hypothesis on the terminal Introspect measurement; the approximate form needs `hMA : IsPVM …` and a sum over the whole alphabet.
- `TypedPredicate.check_*` / `check_*_reversed` pairs (TypedPredicate.lean:122–208): docstrings (TypedPrefixChainBob) record that no symmetry of the supplied Pauli predicate `DP` is assumed, so the reversed orientation is a separate fact.
- `SeedSelectorProg.fieldEnumeration` (:33) vs `Fintype.equivFin`: module docstring records that the explicit little-endian enumeration is the point ("does not identify the enumeration with `Fintype.equivFin`").
- `SourcePadding.fullFamily` cluster (`lift_exact` :47, `fullFamily_exactlyOn` :55, `fullFamily_eval` :59, `sourceGame_fullFamily` :63): listed by the mechanical dead scan, but `MIPRE/Background/Introspection/BinaryPadding.lean:81–108` (`exactPaddedGame`, `exists_exactPadded_perfectPCC`, guarded through `MIPRE/Background/QLD/Axioms.lean`) uses `fullFamily`, `fullFamily_exactlyOn` and `sourceGame_fullFamily`. Live. (The scan's counts for this directory appear not to include `MIPRE/Background/Introspection/`; treat other entries with the same caution.)
- `RegisterTransport.registerOp_{one,sub,mul,conjTranspose,posSemidef}` (RegisterTransport.lean:35–64) restate `Matrix.submatrix_one_equiv`, `submatrix_mul_equiv`, `conjTranspose_submatrix`, `PosSemidef.submatrix` for `registerOp e M := M.submatrix e e`; but `registerOp` is the project's name with 40+ consumer files (`registerOp_mul` alone in 31 external occurrences), so the wrapper API earns its keep. - `RegisterCoordinates.ambientSplit` (:21) is `Equiv.piEquivPiSubtypeProd (· ∈ V)` up to the `{i // i ∈ Vᶜ}` vs `{i // i ∉ V}` subtype (`Finset.mem_compl`); 40 consumer occurrences across the Adaptive* files. Replacing it adds transport lemmas without deleting anything.
- `PVMStateTransfer` ladder (`sum_snorm_state_transfer` → `_le` → `sum_stateSqNorm_…` → `_le` → `sum_bob_…` → `_le`): the four bipartite forms are tagged and consumed by ExtractedStateSoundness.lean; only `sum_snorm_state_transfer_le` (:74) is dead (already in the scan).
- `RestrictedErrorBounds.self_le_errorProfile_scaled` / `one_le_errorProfile` (:19, :38): own-file only, but both are used by `errorProfile_of_restricted_bound` (:51), which Background/Introspection/RestrictedProfileSoundness and NumberedSoundness consume. Live.
- `StrategyReplacementValue.povmValue_stability_of_condWin` (:53): own-file only, consumed by `povmValue_stability_at` (:89). Live.
