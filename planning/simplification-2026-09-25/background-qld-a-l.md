# Simplification survey: `MIPRE/Background/QLD/`, files A–L

Read-only survey, 2026-09-25. Scope: the 28 non-guard files whose basename starts with A–L
(`AncTransport` … `Lines`, 14.9k lines) plus `Axioms.lean` and `planning/qld-campaign.md`.
Every file in scope was read in full. Consumer counts come from a whole-tree `rg -F` on the
final name component (vendored trees excluded, `Axioms.lean` and blueprint tags counted
separately), then from reading the hit; seven `lean_run_code` probes confirmed the claims marked
**[probed]**. Paths are relative to the repository root, `Q/` = `MIPRE/Background/QLD/`.

Two things the mechanical dead scan cannot see, both used below:

* it counts guard-file / blueprint-tag hits as consumers by policy, so a declaration whose only
  consumer is `Axioms.lean` is "dead but tagged" — there are 55 of these in A–L (list at the end);
* it matches by final name component, so a declaration shadowed by another with the same final
  name (`ExplicitSeed.presentation` vs `PauliCL.presentation`) is invisible to it. One genuinely
  dead declaration was found that way (`ExplicitSeed.qldGame_mu_presentation`, row 4).
