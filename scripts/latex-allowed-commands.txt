# amssymb, hyperref, and the leanblueprint package's own (\uses, \lean, \leanok,
# \notready, ...). scripts/lean-coverage.py treats every *other* command used in
# blueprint/src/content/ and not defined in blueprint/src/macros/ as a problem.
#
# Why this file exists: an undefined control sequence does not stop pdflatex under
# nonstopmode. It still writes a PDF, and only returns 1 at the end, so latexmk
# aborts and the blueprint never deploys -- with no "! " line anywhere near the end
# of the CI log to point at. \downsize went undefined that way and the blueprint
# build was red on main for about thirty hours across a dozen merges before anyone
# traced it. There is no pdflatex in a session, so this list is what stands in.
#
